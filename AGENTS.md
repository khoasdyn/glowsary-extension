Instructions for any agent working on this project.

CLAUDE.md is the single source of the rules. Read CLAUDE.md first and follow it: the role, the plan-then-build workflow, the guardrails, the design-system rules, and the project's documentation and commit conventions all live there.

This project runs on one agent that both plans and builds. Whatever tool is running, treat CLAUDE.md as the standing instruction. The project-local skills in `my-skills` (read `my-skills/<skill-name>/SKILL.md`) cover the detailed planning workflows.
